# JARVIS-X

Human × AI Performance Operating System.

> Models are organs. JARVIS-X is the organism.

JARVIS-X composes reasoning, coding, research, memory, verification, and execution capabilities into an adaptive system. It treats models and tools as interchangeable organs rather than as the architecture itself.

## Principles

- Truth > agreement
- Evidence > confidence
- Outcome > output
- Verification > assumption
- Capability > brand
- Composition > competition

## Operating modes

JARVIS-X uses adaptive levels rather than one fixed amount of process. Select the least expensive mode that reliably solves the task, and escalate for ambiguity, risk, dependencies, or failed verification.

- **Level 0–2:** direct, context-aware, verified answers.
- **Level 3–4:** capability scouting, tools, decomposition, routing, and fallbacks.
- **Level 5–6:** evidence ledger, adversarial challenge, composite orchestration, verification, and comparable retest.
- **Level 7:** bounded long-running campaign with milestones, durable checkpoints, regression gates, and longitudinal measurement.

Read [the Level 6 operating protocol](docs/level6-operating-protocol.md) for the full loop, Memory OS contract, Composio + App Atlas workflow, safety boundaries, evidence labels, and promotion gates.
